# Family Vacation Shirt — Claude Brief (reusable)

Paste this whole file into Claude at the start of the next trip's shirt project,
then change only the **TRIP** block. It encodes the design taste we landed on so
we skip the rough drafts and get to a great result fast.

## HOUSE STYLE (keep constant)

**Overall feel:** modern, tonal, editorial, understated. Think boutique
travel-goods brand, not souvenir stand. Restraint over decoration.

**Composition**
- Prefer a **panel / grid of small vignettes** (e.g. 3–4 framed icons in a row)
  OR one clean minimal mark. Lots of negative space.
- **Script family name is the hero.** Set it in an elegant calligraphy/script.
  Everything else is quiet supporting type.
- Support line = destination + dates in **clean, wide-tracked sans caps**
  (e.g. `GREECE · SUMMER 2026`), small.

**Motifs — curated & cultural, never postcard-cliché**
- Choose 3–4 *specific, slightly unexpected* symbols of the place, illustrated
  simply and flatly (with one small detail touch, like fish scales).
- Greece example that worked: sardine, caïque sailboat, olive branch, *mati*
  (evil-eye) amulet.
- **Avoid** the default landmark/badge clichés: big circular crest, flanking
  olive sprigs, giant "GREECE" wordmark, literal Parthenon/Santorini postcards.
  (These were early misses — don't repeat them.)

**Color**
- **Tonal, curated palette** (4–5 harmonious shades), not pure/primary flag
  colors. Greece set that worked: deep navy `#1E3A5F`-ish, powder blue,
  sand/cream `#EDE6D3`-ish, sky blue.
- Add **exactly one warm metallic accent** (mustard/gold ~`#C8992E`) used
  sparingly — a dot, a hairline. Never more than one accent.
- Give backgrounds a **hand-painted / brushstroke texture** where possible
  (gouache feel, rough edges) rather than flat fills — it reads as crafted.

**Type pairing**
- Hero: a real **script** (flowing, confident, generous).
- Support: a **geometric/neutral sans**, uppercase, wide letter-spacing, small.
- Two families max. No Greek-key meander borders, no serif crests.

---

## PROCESS (how to work with me)
1. **Show the palette first** as labeled swatches (name + hex) and let me pick
   before building full designs.
2. Offer **2–3 distinct directions**, not one — but keep each on-brief
   (modern/tonal). No badge-crest versions unless I ask.
3. Iterate on **one** chosen direction; don't regenerate everything each time.
4. Always produce **front + back** (back = script name + roster of member names,
   styled to match — clean column, no heavy borders).
5. Give me **colorways**: light-shirt and dark-shirt versions.

## DELIVERABLES (always)
- **Editable vector SVG** (source of truth) + **transparent** no-background PNG.
- **Print-ready:** vector **PDF** + **300 DPI** transparent PNG at a real print
  size (~12"×13.5" front). Put print files in a `print/` subfolder.
- Keep a small **generator script** so names/dates/colors are one-line edits.
- Commit each step; open/refresh a **draft PR**.

## NICE-TO-HAVES
- A front+back **layout sheet** for quick review.
- If asked to load into Figma: SVGs import as native vectors by drag-drop;
  the `use_figma` API import can be flaky, so offer drag-drop as the fallback.
