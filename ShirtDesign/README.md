# Weidberg Family Vacation — Greece Tank Top

A sleeveless summer tank design for the Weidberg family's July 2026 trip to Greece.

## Files
- `WeidbergFamily_Greece_Tank.svg` — vector source, print-ready and fully editable
- `preview.png` — 1000×1200 rendered preview

## Design
- **Cut:** sleeveless tank (narrow straps, deep armhole scoops) — made for July heat
- **Motif:** Santorini crest (white cliff houses, blue domes, Aegean sea, sun) framed by olive branches
- **Type:** "WEIDBERG / FAMILY VACATION" over "GREECE", a Greek-key (meander) divider, and "SUMMER · JULY 2026"
- **Palette:** Aegean blues (#12496e, #2f7fae, #1c6ea4), olive green, sun gold on white fabric

## Editing / exporting
Open the SVG in any vector editor (Illustrator, Inkscape, Figma). To re-render the PNG:

```bash
python3 -c "import cairosvg; cairosvg.svg2png(url='WeidbergFamily_Greece_Tank.svg', write_to='preview.png', output_width=1000, output_height=1200)"
```

For DTG/screen printing, export the design layer (everything inside the tank silhouette) at 300 DPI; the vector scales to any size without quality loss.
